1) Cos'è un Web Container? Qual è il suo ruolo in un'applicazione JEE? Fai un esempio di Web Container che conosci.

 Un Web Container è un componente di un application server che si occupa di gestire la parte web di un’applicazione Java 
si occupa di eseguire Servlet e JSP gestire le richieste HTTP (request/response) gestire sessioni utente e sicurezza controllare il ciclo di vita delle servlet

Un esempio di Web Container è Apache Tomcat.



2) Qual è la differenza tra un sito web statico e un'applicazione web dinamica? Fai un esempio concreto di ciascuno.

Un sito web statico è composto da pagine HTML fisse che vengono inviate al browser così come sono, senza elaborazione lato server, ad esempio una semplice pagina htlm di vetrina

Un’applicazione web dinamica, invece, genera contenuti   tramite logica lato server e spesso interagisce con un database. ad  sempio: un un sistema di login.

4) Cos'è il protocollo HTTP? Descrivi brevemente cosa succede quando un browser fa una richiesta a un server web (ciclo request-response).

Il protocollo HTTP è il protocollo di comunicazione tra client (browser) e server web.

Il browser invia una REQEUST HTTP (GET, POST, ecc.) > il server riceve la richiesta > elabora la richiesta > il server quindi invia una risposta sulla elaobrazione chiamata RESPONSE HTTP > il browser quindi visualizza il risultato
La RESPONSE contiene dati contenuti in file json o in pagine html oltre che lo STATUS CODE
Il server riceve la richiesta
Il server elabora (eventuale accesso a database o logica)
